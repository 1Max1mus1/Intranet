## 已修复的关键问题

- serve/sync 两进程共享旧内存状态：扫描前重载持久化记录，并有回归验证。
- 自动节点线程竞争：同步引擎加入进程内可重入锁。
- 回环服务器误用于双机：显式监听地址参数。
- 全局限播在热点下不可达：使用子网定向广播验证成功，第二阶段需自动计算广播地址并保留手动 IP 备用。

## 剩余阻塞项

1. 真实热点断网测试因耗时和测试文件被提前同步而多次未形成有效场景，用户决定跳过，日后再根据实际 bug 处理；该项未通过但不继续阻塞当前时间安排。
2. Windows 整机重启恢复已通过：配对保留，重启后发现 0.828 秒、就绪到同步约 0.953 秒，文件内容一致。结果见 `docs/evidence/windows-reboot-result.json`。
3. v5 已验证进程停止后续传：512114688 字节断点，仅续传 24756224 字节，合计 536870912，A/B 哈希一致。结果见 `docs/evidence/process-resume-result.json`。
4. 后续断网场景必须让 A 在 B 输出 AUTO_READY 后再创建源文件，或使用全新同步根目录；watch 只过滤事件，不限制同步文件范围。
