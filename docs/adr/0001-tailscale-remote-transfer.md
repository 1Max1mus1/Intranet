# ADR：第三阶段通过 Tailscale 提供远程文件传输助手

状态：已确认方向，当前不实现。

## 背景

第一、二阶段聚焦同一受信任局域网内的一组目录自动同步。用户另外需要在不同网络之间主动发送文件，类似“文件传输助手”，但不希望为了偶尔传文件而开启持续自动同步。Tailscale 已证明两端可通过虚拟网络连接，当前路径可能是 direct 或 DERP。

## 决策

第三阶段增加一种独立的按需远程传输模式：

- 通过 Tailscale 网络连接两台已配对电脑。
- 用户主动选择文件并发起远程传输，不要求启用或持续运行文件夹自动同步。
- 使用对端 Tailscale 地址或保存的静态设备信息，不依赖普通 UDP 广播发现。
- 延续设备配对和应用层 TLS，显示实际连接路径与失败原因。
- 不设置云端文件存储；若只能走 DERP，必须明确流量经过中继及其性能限制。

## 与同步模式的边界

- 局域网自动同步：持续维护一组同步空间。
- Tailscale 文件传输助手：按需发送用户选择的文件，不承诺目录镜像、删除传播或冲突版本模型。

两种模式可以复用配对、证书、分块、校验和断点续传能力，但不能因为复用传输层就让按需发送隐式启动整个目录同步。

## 后果

- 第三阶段需要静态设备连接和独立的发送/接收流程，不能仅复用 UDP 自动发现。
- Tailscale 的直连或中继状态决定实际体验，不能沿用热点性能数据作为承诺。
- 详细界面、接收确认、队列和验收指标在第三阶段立项时确认；当前不扩展产品实现。
