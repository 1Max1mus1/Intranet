# Intranet 产品需求

## 核心承诺

用户在两台个人 Windows 电脑上交替工作时，同一组工作文件在受信任局域网内自动保持一致；文件完整保存在两端，不依赖云端，日常无需手动复制。

## 用户与设备

- 只服务用户本人的一台台式电脑和一台手提电脑。
- 操作系统均为 Windows；具体版本和硬件在技术验证前登记。
- 不设计账号、多用户、多设备管理或公共共享服务。

## 功能范围

### 同步空间

- 每台电脑各选一个根目录，两边本地路径可以不同。
- 包含全部子目录、文件类型和文件大小，不设置人为的小文件上限。
- 两端都保存完整文件，可离线使用，不提供云端占位符。
- 首版只有一组同步空间，不支持多组独立任务。
- 提供按相对路径配置的简单排除列表；排除项不传播删除，首版不做复杂通配符编辑器。

### 同步行为

- Windows 登录后自动启动并后台常驻，双方进入受信任网络后自动同步。
- 支持新增、修改、删除、重命名和移动。
- 重命名和移动保留文件身份与历史；内容未变时不重新传输整份文件。
- 只同步已经完整保存到磁盘的版本；锁定或持续变化的文件延后重试，不阻塞其他文件。
- 大文件分块传输并支持断点续传。
- 电脑睡眠、关机或离线时保留本地变化，不主动唤醒；双方再次在线后自动补齐。
- 托盘支持暂停、恢复、打开目录、查看状态和退出。暂停期间继续记录本地变化。

### 冲突与恢复

- 双方同时修改同一文件时不自动合并。
- 原路径保留修改时间较新的版本，另一方保存为清楚标识来源的冲突副本。
- 冲突需要通知用户处理。
- 被同步删除的文件和被覆盖的旧版本进入同步目录之外的历史区，可以恢复。
- 历史区默认保留 30 天、最多 20 GB，超限清理最旧的可清理版本；设置可调并显示实际占用。
- 删除记录等同步元数据与历史文件分开管理，避免清理历史后旧文件复活。

### 安全与通知

- 首次使用一次性配对码，之后使用设备证书，无需日常输入同步密码。
- 文件传输加密，不能只依赖网络名称保护文件。
- 只有用户确认的受信任网络允许自动同步；公共或未知网络默认暂停。
- 常规同步静默进行；冲突、持续失败、磁盘不足、安全状态变化和历史清理需要通知。

## 明确不包含

- 多用户、多设备、多组同步空间和云端服务器。
- 在线占位符、自动唤醒电脑和自动合并文档内容。
- 公网文件共享、跨城市同步和复杂权限系统。
- 第一阶段的托盘、主界面、自启动和安装包；它们属于第二阶段，不是被永久砍掉的功能。
- 精美视觉设计；第二阶段以实用、清楚、顺手为准。

## 验收指标

- 双方在线且网络正常时，不超过 10 MB 的文件保存后 5 秒内出现在另一端。
- 双方进入同一受信任网络后 10 秒内发现并开始同步；断网恢复后同样在 10 秒内重连。
- 大文件有效吞吐至少达到同环境 Windows 文件共享实测基线的 70%。
- 广播不可用时允许手动添加 IP 作为备用，不固定主从角色。
- 中断、进程被杀或重启不得产生被误认为成功的半成品，不得破坏原有完整文件。
- 第二阶段完成后，用真实工作目录连续试用至少 7 天，不再手动复制同一批文件，无无法解释的丢失、损坏或旧版本覆盖；重启、睡眠恢复、冲突、历史恢复和暂停均实际可用。
